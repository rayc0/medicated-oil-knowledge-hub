## 香港の伝統ブランド

香港の薬油は長い歴史を持ち、海外への輸出でも知られています。東洋と西洋の原料を取り入れた処方が多く、多用途性に重点を置いているのが特徴です。

- **[白花油コンプリートガイド](white-flower-embrocation-complete-guide.md)** — 香港を代表する薬油の一つで、100年以上の歴史があります。メントール、サリチル酸メチル、ユーカリ油を主成分とし、気分リフレッシュ・痛み緩和・鼻詰まり解消の三役をこなす設計です。
- **[正紅花油コンプリートガイド](red-flower-oil-complete-guide.md)** — 打撲や打ち身向けに設計された製品で、ベニバナ由来の成分を主軸に据え、血行促進と瘀血除去に強みを持ちます。
- **[保心安油コンプリートガイド](po-sum-on-complete-guide.md)** — 香港の老舗ブランドで、クローブとメントールを中心に配合。リフレッシュと駆風効果が特徴で、年配層からの信頼が厚いです。
- **[黄道益活絡油コンプリートガイド](wong-to-yick-complete-guide.md)** — 黄道益氏によって創業された香港の有名なくすり油。中医学に基づく活絡処方で、筋・骨・関節の痛みに焦点を当てています。
- **[萬華油コンプリートガイド](wan-hua-oil-complete-guide.md)** — 香港製で、筋肉のコリや打撲傷に汎用的に使える多用途薬油です。
- **[万応止痛油](wan-ying-zhi-tong-gao/)** — 多機能な外用鎮痛オイルで、香港の家庭では常備品として広く知られています。
- **[双獅行軍散コンプリートガイド](double-prince-complete-guide.md)** — 香港の老舗で、気分覚醒と頭痛緩和を狙った伝統的な処方が特徴です。
- **[鷹標駆風油コンプリートガイド](eagle-brand-medicated-oil-complete-guide.md)** — 100年以上の歴史を持ち、虎標と並ぶ伝統的な駆風油。メントールとユーカリ油を中心に配合されています。
- **[余仁生如意油コンプリートガイド](yu-yee-oil-cap-limau-complete-guide.md)** — 乳幼児・小児向けの穏やかな処方が特徴で、柑橘系をベースにした駆風油です。

## 中国本土ブランド

本土の薬油は中成薬の基準に基づいて生産されることが多く、伝統的な漢方生薬の抽出物を配合した製品が中心です。価格帯が比較的手頃で、市場への供給量も豊富です。

- **[風油精コンプリートガイド](fengyoujing-complete-guide.md)** — 本土で最も普及している日常薬油。メントールとサリチル酸メチルを主成分とし、清涼感とかゆみ止めを狙います。
- **[雲南白薬気霧剤コンプリートガイド](yunnan-baiyao-aerosol-spray-complete-guide.md)** — 雲南白薬が手掛ける外用スプレー。急性の捻挫や打撲時の止血補助などに用いられます。
- **[玉林正骨水コンプリートガイド](yulin-zheng-gu-shui-complete-guide.md)** — 広西・玉林で生産される接骨向けの薬水で、独自のハーブ配合で知られ、アスリートにも利用されています。
- **[三九シリーズ](sanjiu/)** — 現代的な中成薬メーカーが手掛ける外用薬油の製品ライン。
- **[広東百花油](guangdong-baihua/)** — 広東の伝統処方を受け継ぐ製品で、複数の花やハーブのエキスをブレンドしています。
- **[如意珍宝](ruyi-zhenbao/)** — 漢方複合処方による外用油で、血行促進と腫れ・痛みの軽減を狙います。
- **[白花油（本土版）](baihuayou/)** — 本土市場向けに流通するバージョンで、香港版とは処方が若干異なります。
- **[正骨貼](zheng-gu-tie/)** — 接骨・活絡を目的とした外用貼付剤で、整形外科領域の補助としてよく見かけます。
- **[玉樹](yushu/)** — 皮膚のケアを主眼に置いた中草药外用油です。
- **[虎力油](hubiaowan-jin-you/)** — 本土版の処方を採用した駆風薬油。
- **[複方樟脳](compound-camphor/)** — 樟脳を主成分とする複合外用製剤。
- **[祛風油](qufengyou/)** — 伝統的な中薬による駆風・鎮痛の外用油。
- **[清涼油](qingliangyu/)** — 中国本土で広く知られたメントールベースの清涼鎮痛軟膏。
- **[活絡油](huo-luo-you/)** — 活絡通経を主な目的とした複合外用油。
- **[麝香追風](shexiang-zhuifeng/)** — 麝香を配合した比較的高価格帯の追風鎮痛外用製剤。

## 東南アジアブランド

シンガポールやタイの薬油の多くは、南洋へ渡った華人移民の手によって発展してきました。比較的シンプルな処方で、東南アジアをはじめ世界中の華人社会で利用されています。

- **[虎標萬金油コンプリートガイド](tiger-balm-complete-guide.md)** — ミャンマーで生まれ、シンガポールで世界的に広まった国際的定番ブランドです。赤・白の2種類があり、それぞれ用途が分かれています。
- **[斧標駆風油コンプリートガイド](axe-brand-complete-guide.md)** — シンガポールで生まれ、香港でも広く普及した緑の駆風油。メントールとユーカリ油を中心に配合され、胃腸の不快感や頭痛に向く処方です。
- **[均隆駆風油コンプリートガイド](kwan-loong-oil-complete-guide.md)** — 東南アジアの華人家庭で常備されている一本で、駆風とリフレッシュ効果が持続します。
- **[上標油コンプリートガイド](siang-pure-oil-complete-guide.md)** — タイで生産される伝統的な駆風油。頭痛や筋肉の不快感に向けられ、東南アジアや香港で人気があります。
- **[安美露コンプリートガイド](ammeltz-yoko-yoko-complete-guide.md)** — 日本発のブランドで、ジェル状の剤型により局所への塗り広げがしやすく、肩・首周りのケアとして東南アジア市場で広く支持されています。

## ブランド選びのポイント

ブランドごとに得意分野が異なるため、選ぶ際は以下の観点で整理すると判断しやすくなります。

**主な使用目的から選ぶ：**

| 目的 | 候補となるブランド例 |
|------|----------------------|
| 頭痛・気分リフレッシュ | 白花油、保心安油、清涼油 |
| 打撲・捻挫 | 正紅花油、黄道益活絡油、萬華油 |
| 筋肉・関節のコリ・痛み | サロンパス、虎標萬金油（白）、玉林正骨水 |
| 乳幼児のケア | 余仁生如意油（年齢適用の確認が必要） |
| 駆風・腹痛 | 斧標、均隆、保心安油 |
| 乗り物酔い | 白花油、上標油、風油精 |

**体質・使用者から選ぶ際の注意：**

| 注意点 | 対応の方向性 |
|--------|--------------|
| G6PD欠損症（蚕豆症） | 樟脳を含む製品は避ける。詳細は[安全使用ガイド](/zh-hant-hk/safety/)を参照 |
| 妊娠中 | 多くの薬油は使用を避けるべき。医師に相談する |
| 2歳未満の乳幼児 | ほとんどの成人用薬油は使用を避ける |
